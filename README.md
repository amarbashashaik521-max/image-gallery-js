# 🖼️ Image Gallery

A clean and responsive **Image Gallery** built using **HTML, CSS, and JavaScript**. Users can browse through images using **Previous** and **Next** buttons with circular navigation and a modern user interface.

## ✨ Features

* 🖼️ Displays multiple images
* ⬅️ Previous & Next navigation
* 🔄 Circular image navigation (loops from the last image to the first and vice versa)
* 📍 Shows the current image number (e.g., Image 3 / 5)
* 🎨 Modern UI with rounded corners, shadows, and responsive layout
* ⚡ Fast and lightweight – built using vanilla JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation)

## 🚀 How to Run

1. Clone this repository.
2. Open `index.html` in your web browser.
3. Browse the images using the **Previous** and **Next** buttons.
